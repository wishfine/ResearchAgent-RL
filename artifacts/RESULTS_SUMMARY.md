# HotpotQA 实验结果摘要

本目录保存可直接审计的结果指标和数据清单；模型权重、全量轨迹与原始评测/训练日志保留在本机，不纳入 Git。

## 数据与协议

- 数据集：HotpotQA `distractor`，7,000 train / 3,000 eval，train/eval 语料隔离。
- SFT：7,000 条严格教师轨迹，固定为 `SEARCH -> READ -> CITE -> ANSWER`。
- SFT 数据内容哈希：`90090894129eed1ade01cbcdbdb73f5f98044f03e6fe277a720035e32ada4249`。
- 固定小评测：100 条 eval，`selection_seed=20260713`。

## 结论

1. SFT-874 的全量评测确认 n=100 checkpoint 选择有效：相对基座全量，task success 提升 0.4707，citation F1 提升 0.5860，平均单题延迟从 23.02 s 降至 12.87 s。
2. 早期 GRPO100 是有效负对照：它使 action parse success 从固定 n=100 基座的 0.913 降至 0.399。该运行的 KL 系数为 0，且曾出现旧权重同步路径的加载告警，因而不能将退化归因于单一因素。
3. 后续 GRPO 应以 SFT-874 初始化，保留非零 KL、格式/非法动作监控、每个候选 checkpoint 的固定 n=100 评测，并仅对最优候选进行全量 3,000 条评测。
